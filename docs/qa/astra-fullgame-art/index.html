Models and staging review

Independent geometry renders — not in-game screenshots.

The preview browser could not create WebGL. These views export actual game meshes and poses, then render them separately using approximate lighting. They omit textures, alpha-cut foliage, custom shaders, shadows and post-processing. Some use closer review cameras. They reveal model and pose defects, but cannot establish the finished game’s lighting or performance.

The baseline comparisons are qualitative: poses, framing and lighting are not perfectly identical. Use the playable build for acceptance.
