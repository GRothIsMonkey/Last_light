# Horror mechanic template

Add a row to [Horror mechanics registry](../05_HORROR_DESIGN/HORROR_MECHANICS_REGISTRY.md):

```markdown
| H# | Name | What the player perceives | Chapter | Code | Status |
```

For a significant mechanic, document it fully:

### Mechanic: (name)

| | |
|---|---|
| Chapter(s) | |
| Status | 🟡 / ✅ / 💡 |
| Code | `dist/…` (functions, state) |
| Perceived as | What the player sees and hears; what Jamie and Sam do |
| Cause | What triggers it, and can the player trace that cause? |
| Seen-gate | Does it wait to be seen? Cues and timings? |
| Escalation | How it grows across the beat / chapter |
| Physical danger | How close; can it touch anyone? (current canon: nothing has touched anyone) |
| Duration | Seconds; event spacing if it is a chase |
| Muted readability | How it reads with sound off |
| Fallback | What happens if the player ignores or misses it |
| Reset | What Start over / jumps / DEV starts must clear |
| Performance | Lights added? (must not change the light count mid-scene) |
| Tested by | Sim checks / browser captures / human playtest |

Checklist: [Horror design bible](../05_HORROR_DESIGN/HORROR_DESIGN_BIBLE.md) → "Checklist for any new horror beat".
