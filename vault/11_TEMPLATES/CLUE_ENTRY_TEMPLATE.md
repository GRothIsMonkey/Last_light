# Clue entry template

Add a row to the right thread in [Mystery and clue tracker](../01_STORY_BIBLE/MYSTERY_AND_CLUE_TRACKER.md):

```markdown
| Ch | Clue / event | What it shows | Label |
```

If the clue needs more than a row, add a short block under the thread:

### Clue: (name)

| | |
|---|---|
| Chapter / beat | Ch N, beat (phase id if known) |
| Where | Location note link |
| How it is found | Look closer (F) / photograph / overheard / automatic |
| What the player sees | … |
| What the characters say | Exact lines from the code |
| Connects to | Earlier clue(s), later payoff(s) |
| Label | ✅ / 🟡 / 💡 / ❓ |
| Source | `dist/chapterN.js` (function), handoff section |
| New questions raised | Add to [Unanswered questions](../01_STORY_BIBLE/UNANSWERED_QUESTIONS.md) |
