# Templates

Copy a template into the right folder, rename it, and fill it in. In github.dev: right-click the template → **Copy**, then
right-click the destination folder → **Paste**, then rename (F2). On GitHub.com: open the template, click **Raw**, copy
the text, then use **Add file → Create new file** in the destination folder and paste.

| Template | Use it for | Put the copy in |
|---|---|---|
| [CHAPTER_NOTE_TEMPLATE.md](CHAPTER_NOTE_TEMPLATE.md) | A chapter note (new or rebuilt chapter) | `03_CHAPTERS/` |
| [PLAYTEST_NOTE_TEMPLATE.md](PLAYTEST_NOTE_TEMPLATE.md) | Recording a human playtest | `08_PLAYTESTING_AND_ISSUES/` |
| [DECISION_RECORD_TEMPLATE.md](DECISION_RECORD_TEMPLATE.md) | Approving or rejecting a design decision | A row in `00_START_HERE/DECISION_LOG.md` (or a separate note for big decisions) |
| [CLUE_ENTRY_TEMPLATE.md](CLUE_ENTRY_TEMPLATE.md) | A new clue | A row in `01_STORY_BIBLE/MYSTERY_AND_CLUE_TRACKER.md` |
| [FUTURE_CHAPTER_PROPOSAL_TEMPLATE.md](FUTURE_CHAPTER_PROPOSAL_TEMPLATE.md) | A proposal for a future chapter | `03_CHAPTERS/FUTURE_CHAPTERS/` |
| [HORROR_MECHANIC_TEMPLATE.md](HORROR_MECHANIC_TEMPLATE.md) | A new horror mechanic | A row in `05_HORROR_DESIGN/HORROR_MECHANICS_REGISTRY.md` |

Labels to use everywhere: ✅ CONFIRMED CANON · 🟡 IMPLEMENTED BUT UNAPPROVED · 💡 PROPOSED · ❓ UNKNOWN · ⛔ REJECTED.
Issue statuses: 🔴 Open · 🔧 Fixed in code · ⏳ Awaiting playtest · ✅ Human-approved · 💤 Deferred.
