# Last Light development vault

**Start here → [00_START_HERE/START_HERE.md](00_START_HERE/START_HERE.md)** · Every note: [Vault map](00_START_HERE/VAULT_MAP.md)

This folder is the central knowledge base for *Last Light*: story, characters, chapters, world, horror design,
gameplay systems, art and audio direction, playtest feedback, development history and guides for AI assistants.

- It is plain Markdown. It works on GitHub.com, in the browser editor (`github.dev`), and in Obsidian if you ever have it.
- It only documents the game. Nothing in `vault/` is loaded by the game, and nothing here changes the game.
- New to it? Read [How to use this vault](00_START_HERE/HOW_TO_USE_THIS_VAULT.md).
